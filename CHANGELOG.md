# Изменения

## 1.0.0-beta — первая публичная версия

**Анализ (§3).** 14 коллекторов: устройство, Windows и модифицированные сборки (ReviOS, AtlasOS и др.), CPU, все GPU через DXGI, гибридная графика и MUX, экраны (частота, встроенный ли, HDR), ОЗУ (XMP/EXPO, каналы, главные потребители), диски (тип, здоровье, износ, TRIM), температуры (ACPI, nvidia-smi), питание (схема, режим Windows, Modern Standby), таймеры BCD, VBS/HVCI/BitLocker, HAGS/MPO/Game Mode/DVR, автозагрузка, оверлеи, OBS (сцены, буфер повтора, запуск от администратора), сеть, игры Steam/Epic/GOG/Xbox с привязкой к GPU. 27 детекторов — все правила таблицы §3.2 и ещё 7.

**Стратегия (§4).** Класс устройства, 5 целей, явные конфликты целей, уровни риска, порядок «сначала бесплатное и безопасное», исключения в настройках, учёт BitLocker и модифицированных сборок.

**Исправления (§5).** 16 исправлений. Исходное значение пишется в журнал (SQLite) до изменения и фиксируется один раз. Каждое исправление атомарно. Точка восстановления. Откат по исправлению, по сессии или полный. Резервные копии файлов. Сухой прогон.

**Замеры (§6).** ETW-сбор кадров, PresentMon (режим вывода, задержка), синтетический тест D3D11, тест DPC/ISR, точность таймера, пинг и bufferbloat. Несколько прогонов, отброс прогрева, блочный бутстреп с 95 % ДИ, вердикт «лучше / шум / хуже», контроль троттлинга и условий.

**Сценарий (§2).** Сессии с продолжением после перезагрузки (задача планировщика при входе), самопроверка после перезагрузки (применилось ли, синие экраны), автоматическая A/B-проверка спорных настроек с откатом, если нет достоверного улучшения.

**Интерфейс (§8).** WPF: главная, отчёт анализа, замеры с живым графиком, стратегия с галочками, применение, сравнение с графиками и откатом по пункту, история, настройки. Консольная версия `gametune-cli` с мастером `run`.

**Отчёты.** Самодостаточный HTML со SVG-графиками (светлая и тёмная тема), CSV с сырыми фреймтаймами.

**Выпуск (§10).** Установщик (NSIS), портативный zip, проверка обновлений через GitHub Releases (только уведомление), без телеметрии.

### Известные ограничения бета-версии
- Код, работающий с Windows, проверен автоматическими тестами на эмуляции профилей, но в этой версии не проходил проверку на реальных машинах (§11). Первый запуск лучше сделать в виртуальной машине или после создания точки восстановления.
- Файлы не подписаны цифровой подписью — Windows SmartScreen покажет предупреждение.
- Профили NVIDIA/AMD через NVAPI/ADLX — в следующей версии (по ТЗ — версия 2).
