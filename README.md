# Opti

**Портативная программа для Windows 10/11: находит реальные причины лагов, исправляет только то, что мешает, и честно показывает результат замером «до / после».**

Один файл, без установки. Скачали `Opti.exe` и запустили.

- **Сначала диагноз.** Каждое исправление привязано к найденной проблеме. Никаких «наборов твиков».
- **Только измеримый результат.** «Стало лучше» — только если замер это доказал.
- **Всё откатывается.** Исходные значения пишутся в журнал до изменения. Откат по пункту, по сессии или целиком.
- **Честно про железо.** Перегрев, HDD, мало памяти, Wi-Fi — программа так и скажет.
- **Рекомендации с источниками.** Ссылки на Microsoft, Intel, AMD, OBS — а не «говорят, что помогает».

> **Статус: 1.3.1-beta.** Логика покрыта 220+ автоматическими тестами; тесты и сборка проходят на Windows в CI. Новые части (проверка сети, сетевые исправления, игровые твики, аудит реестра, драйверы, расширенная очистка, новый интерфейс) ещё не проверены на большом числе машин — пишите, если что-то работает не так.

Нужна 64-битная Windows 10 или 11. Программа просит права администратора: без них не прочитать события ядра и не поменять системные настройки. Файлы пока без цифровой подписи, поэтому SmartScreen покажет «Неизвестный издатель» → «Подробнее» → «Выполнить в любом случае». Первый запуск чуть дольше: программа распаковывает себя во временную папку.

## Как пользоваться

1. **Главная.** Выберите, что важнее (отклик, плавность, FPS, стрим, тишина), и нажмите «Проанализировать». 30–60 секунд, только чтение. В анализ входит короткая проверка сети: пинг до роутера и до интернета.
2. **Результаты анализа.** Что найдено, почему это важно, на каких данных основан вывод и ссылка на источник.
3. **«Исправить автоматически».** Сначала короткая настройка: отметьте нужные исправления и выберите тест — **полный** (около 2 минут), **быстрый** (2 × 20 с) или **без теста** (только применить; эффект тогда не доказан). Число и длительность прогонов можно поменять. Дальше Opti всё сделает сам: тест → исправления (с точкой восстановления) → перезагрузка, если нужна (после входа программа продолжит сама) → повторный тест → результат.
4. **Результат.** Было → стало с 95 % доверительными интервалами, графики фреймтайма. Каждое исправление можно откатить отдельно.

Можно и вручную: «Выбрать исправления вручную» → замер → галочки → применение. Спорные настройки (HAGS, таймеры) проверяются A/B-замером: остаётся только вариант с доказанным улучшением.

**Драйверы** — все важные драйверы (видео, сеть, звук, чипсет, Bluetooth, накопители) с состоянием: в порядке, старый, стандартный драйвер Microsoft вместо драйвера производителя или драйвера нет. У каждого — ссылка на официальный сайт: NVIDIA, AMD, Intel, Samsung или сайт производителя ноутбука или материнской платы (ASUS, MSI, GIGABYTE, ASRock, Acer, Lenovo, HP, Dell…). Opti сам драйверы не скачивает.

**Очистка** — отдельный раздел: корзина, временные файлы, загруженные обновления Windows, кеш оптимизации доставки, отчёты об ошибках, распакованные установщики драйверов (`C:\NVIDIA`, `C:\AMD`), журналы обслуживания Windows, по желанию — кеш миниатюр, шейдеров, браузеров (Chrome, Edge, Brave, Яндекс, Opera, Vivaldi, Firefox), кеш Discord / Steam / Epic / Spotify / Teams, дампы. Только старые файлы, занятые пропускаются, по ссылкам (symlink/junction) программа не ходит, документы и реестр не трогает.

Отдельно — **«Проверьте сами»**: Opti ничего не удаляет, но показывает, где много места: «Загрузки» (рекомендация разобрать, если больше 5 ГБ), тяжёлые видео больше 1 ГБ (записи игр и фильмы — список со ссылками «показать в Проводнике»), точки восстановления (размер и переход в «Защиту системы»), `Windows.old`.

**Твики** — изменения, которые видно сразу, каждое включается и выключается переключателем (выключение возвращает ровно то, что было до Opti): полное контекстное меню как в Windows 10, быстрое открытие подменю, расширения файлов, Проводник на «Этот компьютер», поиск в «Пуске» без Bing, «Завершить задачу» на панели задач, без рекламы и автоустановки приложений, значки панели задач слева, мгновенное сворачивание окон, автозагрузка без паузы, отключение «Быстрого запуска». Отдельная группа **«Игры и фоновая нагрузка»**: не раздавать обновления Windows в интернет, Edge не работает в фоне, без виджетов, без прозрачности, кнопка Xbox на геймпаде не открывает Game Bar — они освобождают память, процессор и исходящий канал. Твики в «Исправить автоматически» не входят: их включаете вы.

**Программы** — рекомендуемый софт по категориям (диск, мониторинг, драйверы, общение, стрим, игры, системные компоненты, утилиты, браузеры) — только ссылки на официальные сайты: WizTree, CrystalDiskInfo, HWiNFO, LatencyMon, DDU, Discord, OBS, 7-Zip и другие.

Интерфейс следует теме Windows (светлая или тёмная) в фирменных цветах Opti.

## Что проверяется

| Проблема | Что делает Opti |
|---|---|
| Экран не на максимальной частоте | Ставит максимальную частоту |
| Монитор подключён к материнской плате, а не к видеокарте | Объясняет, куда переключить кабель |
| Видеокарта без драйвера, устройства без драйверов | Называет устройства, даёт ссылки на драйверы |
| Windows установлена недавно | Чек-лист после переустановки |
| Игры на встроенной GPU в ноутбуке с двумя видеокартами | Привязывает игры к дискретной GPU |
| OBS «Захват экрана» на двух GPU, OBS от администратора | Меняет на «Захват игры», снимает флаг |
| XMP/EXPO выключен, одноканальная память | Инструкция для BIOS (железо) |
| Ryzen X3D без драйвера чипсета, Intel с P/E-ядрами на Windows 10 | Рекомендация со ссылкой на AMD / Intel |
| Перегрев, HDD, здоровье диска, слабое железо | Честно: это железо |
| Потери пакетов и скачки пинга | Показывает, где проблема: до роутера (Wi-Fi, кабель) или у провайдера |
| Высокий пинг без нагрузки, включён VPN или прокси | Называет причину |
| Wi-Fi на 2,4 ГГц, слабый сигнал, старый стандарт | Что поменять в подключении |
| Гигабитная сетевая карта на 100 Мбит/с | Кабель или порт роутера |
| Торренты, облака и загрузчики в фоне | Называет программы и как их приостановить |
| Отключена автонастройка окна TCP («твик для пинга») | Команда возврата к стандарту |
| Энергосбережение сетевой карты (EEE, Green Ethernet) | Отключает |
| Игры на TCP: алгоритм Нейгла | Отключает (по умолчанию — только для цели «Отклик») |
| Windows давно не обновлялась, выпуск снят с поддержки | Что установить и в каком порядке |
| Видеокарта без новых драйверов (GTX 900/10, RX 400/500 и старше) | Не требует «обновить драйвер», если стоит последний |
| Ноутбук от батареи во время анализа | Просит подключить зарядку |
| Фоновая программа грузит процессор | Называет программу и что с ней сделать |
| Игры на HDD при наличии SSD | Как перенести |
| TRIM для SSD отключён | Включает |
| Питание экономит при работе от сети | Режим и параметры питания только для сети |
| Нестандартные таймеры BCD, ключ MPO | Возвращает стандарт (с учётом BitLocker) |
| Отключённый файл подкачки | Возвращает размер, управляемый системой |
| Ускорение мыши, горячие клавиши залипания | Отключает (мышь — по умолчанию только для цели «Отклик») |
| Устаревшие и стандартные драйверы сети, звука, Bluetooth, чипсета, накопителей | Ссылки на официальные драйверы |
| Вредные «твики» в реестре: LargeSystemCache, отключённый TDR, огромный TdrDelay, отключённые SysMain и Prefetch, нестандартный Win32PrioritySeparation, очистка файла подкачки при выключении, DisablePagingExecutive | Возвращает стандарт Windows |
| Отключённые через реестр обновления Windows, драйверы из Центра обновления, службы wuauserv / BITS / звука, Defender, защиты от Spectre | Возвращает стандарт (на модифицированных сборках — не отмечено по умолчанию) |
| Мало места, ожидающая перезагрузка, HVCI, Wi-Fi, bufferbloat, оверлеи, автозагрузка, Game Mode / DVR, оконная оптимизация | Совет или исправление |

## Исправления

24 исправления, каждое с откатом: частота экрана, привязка игр к GPU, оптимизация оконных игр и VRR, игровой режим, фоновая запись Game Bar, MPO, HAGS (A/B), схема питания, параметры питания от сети, Power Throttling, таймеры BCD, глобальное разрешение таймера (A/B), OBS (захват игры, без администратора), автозагрузка (только выбранное), энергосбережение сетевого адаптера, ускорение мыши, горячие клавиши залипания, файл подкачки, стандартные значения реестра после «оптимизаторов», включение обновлений и защиты Windows, отправка пакетов TCP без задержки (алгоритм Нейгла), энергосбережение сетевой карты (EEE), TRIM для SSD.

Чего Opti не делает: «чистка реестра» (удаление «мусорных» ключей — пользы нет, риск есть; Opti только возвращает стандарт там, где «твик» доказанно вредит), «ускорители ОЗУ», массовое отключение служб, `LargeSystemCache`, «сетевые твики» без доказанного эффекта.

## Честное сравнение

- Метрики: средний FPS, 1 % и 0,1 % low, фреймтайм — медиана, p95, p99, разброс.
- Прогрев отбрасывается. Несколько прогонов. 95 % ДИ — блочный бутстреп (блоки ~1 с).
- «Лучше» или «хуже» — только если интервалы не пересекаются **и** разница больше разброса между прогонами.
- Прогоны с троттлингом исключаются. Разные условия (разрешение, экран, питание) помечают сравнение как ненадёжное.

## Безопасность

- Исходное значение пишется в журнал (`C:\ProgramData\Opti\journal.db`) **до** изменения. Не удалось сохранить — изменение не выполняется.
- Перед первым применением — точка восстановления Windows.
- В игры ничего не внедряется (ETW только читает события), античиты не реагируют.
- Телеметрии нет. Сеть используется для проверки обновлений (выключается), короткого пинга до роутера и `1.1.1.1` во время анализа (выключается в настройках, адрес меняется) и теста сети под нагрузкой по вашей команде.
- Удалить Opti — удалить `Opti.exe`. Перед этим можно откатить всё: «История» → «Откатить все изменения Opti».
- Данные GameTune 1.0.0-beta переносятся автоматически, откат старых изменений работает.

## Командная строка

```bash
opti-cli doctor
```

```bash
opti-cli run --goal latency --mode synthetic
```

Команды `run`, `resume`, `analyze`, `plan`, `measure`, `apply`, `ab`, `compare`, `report`, `rollback`, `history`, `latency`, `net`, `version`, `doctor` описаны в `opti-cli help`.

## Сборка из исходников

Нужен .NET 10 SDK. Всё, кроме запуска интерфейса и ETW, собирается и тестируется и в Linux.

```bash
dotnet test
```

```bash
build/publish.sh
```

Релиз собирает GitHub Actions (`.github/workflows/release.yml`): пуш в ветку `release` → тесты на Windows → портативная сборка → релиз с тегом `v<версия>`.

```
src/Opti.Core         модели, IDetector / IFix, журнал, стратегия
src/Opti.Native       P/Invoke: экран, DXGI, HAGS, питание; разбор вывода утилит
src/Opti.Analysis     17 коллекторов, 53 детектора
src/Opti.Fixes        бэкенды настроек, 24 исправления, журнал SQLite, откат
src/Opti.Measure      метрики, бутстреп, ETW (кадры, DPC/ISR), сеть
src/Opti.Bench        синтетический тест D3D11 (встроен в Opti.exe, ключ --bench)
src/Opti.Workflow     сессии, перезагрузка, A/B, очистка, HTML-отчёт, обновления
src/Opti.ViewModels   логика интерфейса (тестируется без Windows)
src/Opti.App          интерфейс WPF (Fluent) → Opti.exe
src/Opti.Cli          командная строка → opti-cli.exe
tests/Opti.Tests      тесты; Profiles/*.json — профили шести типов ПК
```
