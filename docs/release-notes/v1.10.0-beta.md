**Opti 1.10.0-beta** — портативная программа для Windows 10/11: находит реальные причины лагов, исправляет только то, что мешает, и честно показывает результат замером «до / после».

## Скачать
| Файл | Что это |
|---|---|
| `Opti.exe` | Программа. Один файл, без установки — просто запустите |
| `Opti.Dev.exe` | Та же программа для тестеров: рядом с собой ведёт `dev.zip` с диагностикой (профиль ПК, находки, журналы, вывод системных утилит; имя пользователя и компьютера скрыты). Если что-то работает не так, пришлите этот файл |
| `opti-cli.exe` | Командная строка для опытных |
| `SHA256SUMS.txt` | Контрольные суммы |

Нужна 64-битная Windows 10/11. Файлы без цифровой подписи, поэтому SmartScreen покажет «Неизвестный издатель» → «Подробнее» → «Выполнить в любом случае».

## Что нового
- **Карточки находок**: раскройте находку и увидите «Что изменит Opti» — суть, риск, надёжность, перезагрузку и откат.
- **Главная** показывает факты последнего анализа вместо абстрактных оценок.
- **Итог сравнения**: отдельно «исправлено» и «измерено» (тест синтетический, не ваша игра).
- **Надёжность**: обновления берутся из `alexkuz2014/Opti`; откат не затирает то, что вы изменили после Opti; запись проверяется повторным чтением.
- **Микрофризы** на странице «Фризы», проверки Wi-Fi-канала, износа батареи и двух антивирусов.

## Бета
Новые части ещё не проверены на большом числе машин. Если что-то работает не так — напишите в Issues, приложив отчёт анализа (HTML) или `dev.zip` от `Opti.Dev.exe`.
