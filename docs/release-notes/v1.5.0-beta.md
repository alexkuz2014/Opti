**Opti 1.5.0-beta** — портативная программа для Windows 10/11: находит реальные причины лагов, исправляет только то, что мешает, и честно показывает результат замером «до / после».

## Скачать
| Файл | Что это |
|---|---|
| `Opti.exe` | Программа. Один файл, без установки — просто запустите |
| `opti-cli.exe` | Командная строка для опытных |
| `SHA256SUMS.txt` | Контрольные суммы |

Нужна 64-битная Windows 10/11. Файлы без цифровой подписи, поэтому SmartScreen покажет «Неизвестный издатель» → «Подробнее» → «Выполнить в любом случае».

## Что нового
- **Страница «Игра»**: «Перед игрой» — закрыть выбранные фоновые программы одной кнопкой; «Приглушать фон во время игры» — пониженный приоритет браузерам и лаунчерам, пока идёт игра.
- **Метки надёжности** у исправлений и твиков: что проверено, что зависит от ПК, что пока гипотеза.
- **Новые твики**: приоритет игр в планировщике мультимедиа, снятие сетевого ограничения для мультимедиа, запрет фоновой работы приложений Магазина.
- **Resizable BAR**: Opti видит, что он выключен, и объясняет, как включить.
- Всё из 1.4.x: ограничения загрузки (msconfig), схема «Максимальная производительность», профиль GTA V / Majestic RP, проверка сети, новый интерфейс.
