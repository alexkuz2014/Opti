**Opti 1.7.0-beta** — портативная программа для Windows 10/11: находит реальные причины лагов, исправляет только то, что мешает, и честно показывает результат замером «до / после».

## Скачать
| Файл | Что это |
|---|---|
| `Opti.exe` | Программа. Один файл, без установки — просто запустите |
| `Opti.Dev.exe` | Та же программа для тестеров: рядом с собой ведёт `dev.zip` с диагностикой (профиль ПК, находки, журналы, вывод системных утилит; имя пользователя и компьютера скрыты). Если что-то работает не так, пришлите этот файл |
| `opti-cli.exe` | Командная строка для опытных |
| `SHA256SUMS.txt` | Контрольные суммы |

Нужна 64-битная Windows 10/11. Файлы без цифровой подписи, поэтому SmartScreen покажет «Неизвестный издатель» → «Подробнее» → «Выполнить в любом случае».

## Что нового
- **Контроль сброса настроек**: плашка «Восстановить» на главной и `opti-cli verify`, если обновление Windows или драйвера сбросило то, что настроил Opti.
- **Режим эффективности (EcoQoS)** для фоновых процессов во время игры.
- **Проверки железа**: ширина шины PCIe видеокарты, перегрев NVMe, режим MSI видеокарты, RSS (с исправлением).
- **Лимит FPS** под монитор с учётом VRR.
- **«Копировать сводку»** — обезличенная карточка ПК для техподдержки.
- Всё из 1.6.x: помощник по загрузке игр, страница «Игра», метки надёжности и другое.

## Бета
Новые части ещё не проверены на большом числе машин. Если что-то работает не так — напишите в Issues, приложив отчёт анализа (HTML).
