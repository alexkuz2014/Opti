**Opti 1.6.0-beta** — портативная программа для Windows 10/11: находит реальные причины лагов, исправляет только то, что мешает, и честно показывает результат замером «до / после».

## Скачать
| Файл | Что это |
|---|---|
| `Opti.exe` | Программа. Один файл, без установки — просто запустите |
| `opti-cli.exe` | Командная строка для опытных |
| `SHA256SUMS.txt` | Контрольные суммы |

Нужна 64-битная Windows 10/11. Файлы без цифровой подписи, поэтому SmartScreen покажет «Неизвестный издатель» → «Подробнее» → «Выполнить в любом случае».

## Что нового
- **Загрузка игр**: на странице «Игра» — где лежит каждая игра (HDD, SSD, NVMe, USB) и что с этим делать; находки «Как ускорить загрузку игр», «Диск занят» (с названием программы, которая грузит диск) и «Диск с играми почти заполнен».
- Fortnite: подсказки про шейдеры DirectX 12. Антивирус: честно, что исключение папки игры ускоряет загрузку и снижает защиту.
- Очистка кэша шейдеров предупреждает, что после неё игры грузятся дольше.
- Всё из 1.5.x: страница «Игра», метки надёжности, Resizable BAR, ПО периферии.

Новые части ещё не проверены на большом числе машин. Если что-то работает не так — напишите в Issues, приложив отчёт анализа (HTML).
