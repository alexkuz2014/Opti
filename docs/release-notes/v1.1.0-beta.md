**Opti** — новое имя GameTune. Портативная программа для Windows 10/11: находит реальные причины лагов, исправляет только то, что мешает, и честно показывает результат замером «до / после».

## Скачать
| Файл | Что это |
|---|---|
| `Opti.exe` | Программа. Один файл, без установки — просто запустите |
| `opti-cli.exe` | Командная строка для опытных |
| `SHA256SUMS.txt` | Контрольные суммы |

Нужна 64-битная Windows 10/11. Файлы без цифровой подписи, поэтому SmartScreen покажет «Неизвестный издатель» → «Подробнее» → «Выполнить в любом случае».

## Что нового
- **Один портативный файл** вместо установщика. Синтетический тест встроен.
- **Новый интерфейс** на системной теме Fluent: светлая/тёмная тема и акцентный цвет Windows.
- **«Исправить автоматически»**: тест → исправления → перезагрузка, если нужна (продолжение само) → тест → результат.
- **Синтетический тест по умолчанию** (около 2 минут); замер в своей игре — по желанию.
- **Бережная очистка**: корзина, временные файлы, обновления, кеши, отчёты об ошибках. Только старые файлы, ссылки не обходятся, документы не трогаются.
- **Проверки после переустановки Windows**: монитор в материнской плате, видеокарта и устройства без драйверов, чек-лист свежей установки, драйвер чипсета для Ryzen X3D, Intel P/E-ядра на Windows 10, ожидающая перезагрузка, отключённый файл подкачки.
- **Новые исправления**: ускорение мыши, горячие клавиши залипания, файл подкачки — всё с откатом.
- **Рекомендации со ссылками** на Microsoft, Intel, AMD, OBS.

## Исправлено
- Ложный «троттлинг» на видеокартах NVIDIA: из-за него прогоны помечались ненадёжными.
- Определение системного диска, работа с корзиной в x64.
- Уязвимость SQLite (GHSA-2m69-gcr7-jv3q) — обновлена нативная библиотека.

## Переход с GameTune 1.0.0-beta
Журнал отката и история переносятся автоматически при первом запуске Opti — изменения, сделанные GameTune, можно откатить из «Истории». Установленную GameTune можно удалить через «Приложения» (на вопрос об откате можно ответить «Нет»: журнал уже у Opti).

## Бета
Новые части (интерфейс Fluent, очистка, автоцикл) покрыты автоматическими тестами, но на многих машинах ещё не проверены. Если что-то выглядит или работает не так — опишите в issue или пришлите скриншот.
