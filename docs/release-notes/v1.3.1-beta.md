**Opti 1.3.1-beta** — портативная программа для Windows 10/11: находит реальные причины лагов, исправляет только то, что мешает, и честно показывает результат замером «до / после».

## Скачать
| Файл | Что это |
|---|---|
| `Opti.exe` | Программа. Один файл, без установки — просто запустите |
| `opti-cli.exe` | Командная строка для опытных |
| `SHA256SUMS.txt` | Контрольные суммы |

Нужна 64-битная Windows 10/11. Файлы без цифровой подписи, поэтому SmartScreen покажет «Неизвестный издатель» → «Подробнее» → «Выполнить в любом случае».

## Что нового
- **Новый интерфейс главной**: без большого баннера, цель и запуск анализа в одной карточке, ход анализа по шагам, разделы-плитки, строка о действующих изменениях Opti.
- **Анализ**: кнопка «Исправить автоматически» закреплена внизу, добавлена «Повторить анализ».
- **Раскрывающиеся карточки** переделаны: заголовок на всю ширину, длинный текст переносится.
- Всё из 1.3.0-beta: проверка сети в анализе, сетевые исправления, поддержка старого железа, игровые твики.

## Бета
Новые части ещё не проверены на большом числе машин. Если что-то работает не так — напишите в Issues, приложив отчёт анализа (HTML).
