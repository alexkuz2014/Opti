**Opti 1.11.0-beta** — портативная программа для Windows 10/11: находит реальные причины лагов, исправляет только то, что мешает, и честно показывает результат замером «до / после».

## Скачать
| Файл | Что это |
|---|---|
| `Opti.exe` | Программа. Один файл, без установки — просто запустите |
| `Opti.Dev.exe` | Та же программа для тестеров: рядом с собой ведёт `dev.zip` с диагностикой (профиль ПК, находки, журналы, вывод системных утилит; имя пользователя и компьютера скрыты). Если что-то работает не так, пришлите этот файл |
| `opti-cli.exe` | Командная строка для опытных |
| `SHA256SUMS.txt` | Контрольные суммы |

Нужна 64-битная Windows 10/11. Файлы без цифровой подписи, поэтому SmartScreen покажет «Неизвестный издатель» → «Подробнее» → «Выполнить в любом случае».

## Что нового
- **39 новых твиков**: приватность и реклама, Проводник, панель задач, ввод, диагностика. Каждый выключается тем же переключателем.
- **Страница «Твики»**: поиск, счётчики по разделам, «Выключить все», сохранение и загрузка набора из файла рядом с программой.
- **7 новых проверок**: старый BIOS, виртуальная машина, выключенные точки восстановления, разные модули памяти, медленный основной монитор, совет для 60 Гц, тяжёлое разрешение.
- Всё из 1.10: карточки находок, факты на главной, откат без затирания ручных правок.
## Бета
Новые части ещё не проверены на большом числе машин. Если что-то работает не так — напишите в Issues, приложив отчёт анализа (HTML) или `dev.zip` от `Opti.Dev.exe`.
