**Opti 1.8.0-beta** — портативная программа для Windows 10/11: находит реальные причины лагов, исправляет только то, что мешает, и честно показывает результат замером «до / после».

## Скачать
| Файл | Что это |
|---|---|
| `Opti.exe` | Программа. Один файл, без установки — просто запустите |
| `Opti.Dev.exe` | Та же программа для тестеров: рядом с собой ведёт `dev.zip` с диагностикой (профиль ПК, находки, журналы, вывод системных утилит; имя пользователя и компьютера скрыты). Если что-то работает не так, пришлите этот файл |
| `opti-cli.exe` | Командная строка для опытных |
| `SHA256SUMS.txt` | Контрольные суммы |

Нужна 64-битная Windows 10/11. Файлы без цифровой подписи, поэтому SmartScreen покажет «Неизвестный издатель» → «Подробнее» → «Выполнить в любом случае».

## Что нового
- **«Максимум оптимизации»**: одна кнопка — нажали и отошли на 10–15 минут. Анализ, тест, все безопасные исправления, твики, очистка, драйверы из Центра обновления Windows, перезагрузка (сама, через 60 секунд, отсчёт можно отменить), повторный тест и результат.
- Исправления и твики откатываются одной кнопкой; драйверы — в Диспетчере устройств.
- Всё из 1.7.x: «Оптимизировать» и «Только проверить», подбор нагрузки теста, исправления по первому запуску.

## Бета
Новые части ещё не проверены на большом числе машин. Если что-то работает не так — напишите в Issues, приложив отчёт анализа (HTML).
