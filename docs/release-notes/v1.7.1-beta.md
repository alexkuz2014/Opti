**Opti 1.7.1-beta** — портативная программа для Windows 10/11: находит реальные причины лагов, исправляет только то, что мешает, и честно показывает результат замером «до / после».

## Скачать
| Файл | Что это |
|---|---|
| `Opti.exe` | Программа. Один файл, без установки — просто запустите |
| `Opti.Dev.exe` | Та же программа для тестеров: рядом с собой ведёт `dev.zip` с диагностикой (профиль ПК, находки, журналы, вывод системных утилит; имя пользователя и компьютера скрыты). Если что-то работает не так, пришлите этот файл |
| `opti-cli.exe` | Командная строка для опытных |
| `SHA256SUMS.txt` | Контрольные суммы |

Нужна 64-битная Windows 10/11. Файлы без цифровой подписи, поэтому SmartScreen покажет «Неизвестный издатель» → «Подробнее» → «Выполнить в любом случае».

## Что нового
- **«Оптимизировать» одной кнопкой**: анализ, тест, безопасные исправления, повторный тест и результат. Три пресета вместо пяти целей.
- **Тест тяжелее**: нагрузка подбирается под компьютер, чтобы разница была видна.
- **Исправлено**: исправление сетевого адаптера, нечитаемые ошибки PowerShell, ложный «сброс» настроек OBS, белая подложка под карточками режима.
- Всё из 1.7.0: контроль сброса настроек, режим эффективности для фона, проверки железа, сводка для техподдержки.

## Бета
Новые части ещё не проверены на большом числе машин. Если что-то работает не так — напишите в Issues, приложив отчёт анализа (HTML).
