**Opti 1.3.0-beta** — портативная программа для Windows 10/11: находит реальные причины лагов, исправляет только то, что мешает, и честно показывает результат замером «до / после».

## Скачать
| Файл | Что это |
|---|---|
| `Opti.exe` | Программа. Один файл, без установки — просто запустите |
| `opti-cli.exe` | Командная строка для опытных |
| `SHA256SUMS.txt` | Контрольные суммы |

Нужна 64-битная Windows 10/11. Файлы без цифровой подписи, поэтому SmartScreen покажет «Неизвестный издатель» → «Подробнее» → «Выполнить в любом случае».

## Что нового
- **Проверка сети в анализе**: пинг до роутера и до интернета — видно, где теряются пакеты: дома или у провайдера.
- **Новые сетевые проверки**: высокий пинг, VPN и прокси, слабый Wi-Fi, кабель на 100 Мбит/с, торренты и облака в фоне, отключённая автонастройка TCP.
- **Сетевые исправления с откатом**: энергосбережение сетевой карты (EEE) и алгоритм Нейгла для игр на TCP.
- **Windows без обновлений и выпуски без поддержки**: что установить и в каком порядке.
- **Старые видеокарты** (GTX 900/10, RX 400/500 и старше): без ложного «драйвер устарел», с советом, где брать FPS.
- **Фон и диски**: программа, грузящая процессор; игры на HDD при наличии SSD; включение TRIM.
- **Игровые твики**: не раздавать обновления в интернет, Edge без фоновой работы, без виджетов и прозрачности, кнопка Xbox без Game Bar.
