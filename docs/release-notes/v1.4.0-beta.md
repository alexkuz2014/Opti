**Opti 1.4.0-beta** — портативная программа для Windows 10/11: находит реальные причины лагов, исправляет только то, что мешает, и честно показывает результат замером «до / после».

## Скачать
| Файл | Что это |
|---|---|
| `Opti.exe` | Программа. Один файл, без установки — просто запустите |
| `opti-cli.exe` | Командная строка для опытных |
| `SHA256SUMS.txt` | Контрольные суммы |

Нужна 64-битная Windows 10/11. Файлы без цифровой подписи, поэтому SmartScreen покажет «Неизвестный издатель» → «Подробнее» → «Выполнить в любом случае».

## Что нового
- **Ограничения загрузки (msconfig)**: Opti находит и снимает урезанное число процессоров, предел памяти и режим одного процессора. Значение «число процессоров» на максимуме ничего не ускоряет — это Opti тоже объясняет.
- **Максимальная производительность**: на настольном ПК создаётся скрытая схема питания, если её нет.
- **GTA V и Majestic RP**: что в настройках игры даёт FPS на вашем ПК, по убыванию эффекта. Файлы игры не меняются.
- **Подсказки по панели NVIDIA и Radeon Software**: Reflex, режим низкой задержки, лимит кадров.
- Всё из 1.3.x: проверка сети в анализе, сетевые исправления, старое железо, игровые твики, новый интерфейс.
