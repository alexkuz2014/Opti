**Opti 1.5.1-beta** — портативная программа для Windows 10/11: находит реальные причины лагов, исправляет только то, что мешает, и честно показывает результат замером «до / после».

## Скачать
| Файл | Что это |
|---|---|
| `Opti.exe` | Программа. Один файл, без установки — просто запустите |
| `opti-cli.exe` | Командная строка для опытных |
| `SHA256SUMS.txt` | Контрольные суммы |

Нужна 64-битная Windows 10/11. Файлы без цифровой подписи, поэтому SmartScreen покажет «Неизвестный издатель» → «Подробнее» → «Выполнить в любом случае».

## Что нового
- **Фоновое ПО периферии** (G HUB, Synapse, Armoury Crate, SteelSeries GG, iCUE): Opti замечает и объясняет, что с ним делать.
- **Подсказки по видеодрайверу**: загрузка видеокарты 90–95 %, чистая установка драйвера, «улучшайзеры» монитора.
- Всё из 1.5.0: страница «Игра», метки надёжности, Resizable BAR, новые твики.

## Бета
Новые части ещё не проверены на большом числе машин. Если что-то работает не так — напишите в Issues, приложив отчёт анализа (HTML).
